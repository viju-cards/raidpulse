Setup Guide

Get your live raid & Mythic+ progress on stream in a few minutes. You need WoW (Retail), OBS and the free ProgDeck download.

Core setup

Three things and you're live: run it, add it to OBS, install the addon.

1

Download and run

Download ProgDeck.zip, unzip it anywhere, and run Overlay.exe.

ProgDeck opens its control panel (the settings) in its own app window. You can close that window anytime — the overlay keeps running in the background so OBS still gets it. To fully quit ProgDeck, use Quit app in the panel.

2

Add the overlay to OBS

In OBS, add a new Browser Source and set:

  • URL: http://127.0.0.1:8787/overlay.html
  • Width 1920, Height 360 — place it at the bottom of your scene
  • In the source Properties, tick "Refresh browser when scene becomes active" so it loads automatically when OBS starts

Put your webcam as its own source over the transparent CAM area on the left.

3

Install the WoW addon (for live boss HP)

  • Copy the BossPixelExport folder from the ZIP into your WoW Interface/AddOns folder
  • In game, type /reload (or restart WoW)

Important: the small coloured pixels at the bottom-left of your screen must not be covered by anything (for example your chat box). The addon enables your combat log automatically.

4

Configure

The control panel is already open — or open http://127.0.0.1:8787/home in your browser. Set your streamer name, assign boss and dungeon images, pick a theme, and more. That's it — you're live.

Optional features

All optional — set up only what you want, everything lives in the control panel.

Twitch chat bot

Your viewers can pull live info straight from chat: !pull !best !recap !key !deaths. The bot answers instantly from your current session data.

How to set it up:

  • Go to twitchtokengenerator.com, authorize the account that should post the replies (your main account or a dedicated bot account) and select the scopes chat:read and chat:edit. Copy the Access token it shows — not the refresh token or the client ID.
  • In ProgDeck, open the Twitch Bot tile and enter your Channel (your Twitch name), the Bot account (the account the token belongs to) and paste the Access token.
  • Turn the commands you want on or off, and optionally reword their replies.
  • Click Save & connect — it should report "Connected to Twitch chat".

Keep the token private — never show it on stream. Anyone who has it can post as your bot.

Session recap auto-post

At the end of a session (a new WoW login) ProgDeck automatically posts a summary of your night — plus a recap image — to Twitch chat and/or Discord. You can also post it any time mid-session with the Post recap now button.

How to set it up:

  • Twitch chat: tick "Post summary + image link in Twitch chat" (this needs the chat bot connected, see above).
  • Discord: tick "Post to Discord" and add a webhook URL. To get one, open the target channel in Discord → Edit Channel → Integrations → Webhooks → New Webhook, then Copy Webhook URL and paste it in.
  • Click Save & connect Discord to verify — a test message appears in the channel. Use Send test to preview the full recap post.

The recap image is uploaded to catbox.moe so it can be shared as a public link.

OBS Auto-Clip

Automatically records every boss pull through OBS and keeps only the kills — wipes and resets are discarded. You get a clean highlight folder without lifting a finger.

How to set it up:

  • In OBS, open Tools → WebSocket Server Settings, enable the server, and note the Port (default 4455) and the Password.
  • In ProgDeck, open the OBS Auto-Clip tile, tick enable, and enter the host (127.0.0.1), the port and the password. Optionally choose a clip folder.
  • Click Save & connect.

If OBS is already recording your session, ProgDeck won't touch that recording.

Boss & Mythic+ images and themes

Make the overlay yours with custom art and colours.

  • Boss / Mythic+ images: under Images, pick the season and assign an image per boss or dungeon — via the file picker or drag & drop.
  • Themes: under Overlay look → Themes, pick a ready-made theme (accent colour, background, pattern) — including WoW-class colours and Sakura — or set the accent, background and pattern yourself.

WarcraftLogs import

By default ProgDeck starts counting pulls from zero. This import fills in your guild's history from WarcraftLogs, so your pull counts and best tries are complete from day one instead of restarting. It enters the number of pulls up to the first kill for each boss and difficulty your guild has already killed — so a boss you've long killed shows its real prog count, not "1".

How to set it up:

  • Get a WarcraftLogs API key: log in at warcraftlogs.com, open your Profile → Web API, create a client (give it any name) and copy the V1 API key.
  • In ProgDeck, open the WarcraftLogs Import tile and enter the API key, your Guild name, Server (realm) and Region (EU / US), then pick the Raid.
  • Click Import pulls — ProgDeck reads your guild's public reports and fills in the historical pull counts.

Troubleshooting

The overlay doesn't show in OBS
Make sure Overlay.exe is running, then right-click the browser source → Refresh. Check the URL is exactly http://127.0.0.1:8787/overlay.html.
Boss HP doesn't update
The coloured pixels at the bottom-left are covered (move your chat box), or the addon isn't loaded — type /reload in game and check the BossPixelExport folder is in Interface/AddOns.
The control panel didn't open
Open it manually at http://127.0.0.1:8787/home. The server runs even without the window.
Outside a raid I only see the cam
That's by design — the boss overlay appears in raids, the Mythic+ overlay when you start a keystone. You can change this in the settings.
