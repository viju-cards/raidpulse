Setup Guide

Get your live raid & Mythic+ progress on stream in a few minutes. You need WoW (Retail), OBS and the free ProgDeck download.

Core setup

Three things and you're live: install it, add it to OBS, install the addon.

1

Download and install

Download ProgDeck-Updater.exe, run it, pick an empty folder for a fresh install and click Install. It sets everything up for you (and can install the WoW addon in the same step — see step 3).

Then run Overlay.exe from that folder. ProgDeck opens its control panel (the settings) in its own app window — you can close that window anytime, the overlay keeps running in the background so OBS still gets it. To fully quit, use Quit app in the panel.

First start: Windows SmartScreen may appear ("More info" → "Run anyway") — normal for unsigned apps.

2

Add the overlay to OBS

In OBS, add a new Browser Source and set:

  • URL: http://127.0.0.1:8787/overlay.html
  • Width 1920, Height 360 — place it at the bottom of your scene
  • In the source Properties, tick "Refresh browser when scene becomes active" so it loads automatically when OBS starts

Put your webcam as its own source over the transparent CAM area on the left.

Tip: for a narrower panel that leaves room for a damage meter, enable Compact / narrow in the overlay settings (or add ?narrow=1 to the URL).

3

Install the WoW addon (for live boss HP)

The updater can do this for you — it asks for your Interface/AddOns folder and copies the addon in. To do it by hand instead:

  • Copy the BossPixelExport folder into your WoW Interface/AddOns folder
  • In game, type /reload (or restart WoW)

Important: the small coloured pixels at the bottom-left of your screen must not be covered by anything (for example your chat box). The addon enables your combat log automatically. Run WoW in borderless windowed mode.

4

Configure

The control panel is already open — or open http://127.0.0.1:8787/home in your browser. Set your streamer name, assign boss and dungeon images (under Images), pick a theme, and more. That's it — you're live.

Optional features

All optional — set up only what you want, everything lives in the control panel.

Mythic+ best times

On keystone start the overlay shows your fastest previous run for that dungeon & key level (Best), or First +X if it's a new one. Fill them under Connections in two ways:

  • Import from Raider.IO: enter your region, realm and character — your personal bests per dungeon and level are pulled in automatically (free, no key needed).
  • Manual editor: pick a character and season, then type your times per dungeon and key level (+2 … +24) by hand.

New times are also recorded automatically on every finished key — the fastest per character, dungeon & level is kept.

Boss & Mythic+ images and themes

Make the overlay yours with custom art and colours.

  • Boss / Mythic+ images: under Images, pick the raid or season and assign an image per boss or dungeon — via the file picker or drag & drop. A default set is already included.
  • Themes: under Overlay look → Themes, pick a ready-made theme (accent colour, background, pattern) — including WoW-class colours and Sakura — or set the accent, background and pattern yourself.

Non-English client: boss and dungeon images are matched by encounter / challenge-map ID, so the bundled English-named images work on German and other localized clients too.

WarcraftLogs import

By default ProgDeck starts counting pulls from zero. This import fills in your guild's history from WarcraftLogs, so your pull counts and best tries are complete from day one instead of restarting. It enters the number of pulls up to the first kill for each boss and difficulty your guild has already killed — so a boss you've long killed shows its real prog count, not "1".

How to set it up:

  • Get a WarcraftLogs API key: log in at warcraftlogs.com, open your Profile → Web API, create a client (give it any name) and copy the V1 API key.
  • In ProgDeck, under Connections open the WarcraftLogs Import tile and enter the API key, your Guild name, Server (realm) and Region (EU / US), then pick the Raid.
  • Click Import pulls — ProgDeck reads your guild's public reports and fills in the historical pull counts.

Keeping ProgDeck updated

To update, just grab the latest ProgDeck-Updater.exe from this site, run it, pick your existing ProgDeck folder and click Install.

  • Your settings, API keys and Mythic+ best times are always kept — they live in %APPDATA%\ProgDeck, outside the program folder.
  • The updater can also refresh the BossPixelExport addon for you; afterwards just /reload in WoW.
  • The installed version is shown in ProgDeck's sidebar (top-left) and in the updater.

Troubleshooting

The overlay doesn't show in OBS
Make sure Overlay.exe is running, then right-click the browser source → Refresh. Check the URL is exactly http://127.0.0.1:8787/overlay.html.
Boss HP doesn't update
The coloured pixels at the bottom-left are covered (move your chat box), or the addon isn't loaded — type /reload in game and check the BossPixelExport folder is in Interface/AddOns.
Windows blocks the download or start
The app is unsigned, so SmartScreen may warn: click "More info" → "Run anyway". Your browser may also ask to keep the .exe.
The control panel didn't open
Open it manually at http://127.0.0.1:8787/home. The server runs even without the window.
Outside a raid I only see the cam
That's by design — the boss overlay appears in raids, the Mythic+ overlay when you start a keystone. You can change this in the settings.
